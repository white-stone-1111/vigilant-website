@endors/widgets & the endors CLI

The browser half of the integration story. These packages are public by design — no API key ever belongs in frontend code.

@endors/widgets — one call, one live wall

bash 
npm install @endors/widgets
js 
import { mount } from "@endors/widgets";

mount(document.getElementById("wall"), { embedId: "your-embedding-id" });

Two helpers cover the other common shapes:

  • mountAt(selector, options) — mount into a CSS selector, e.g. mountAt("#reviews", { embedId }).
  • mountAll() — mount every [data-endors-embed-id] container on the page (embedId comes from each container's attribute; other options pass through). It reads data-endors-embed-id and data-embed-height only — the data-endors-match attribute is the copy-paste snippet's feature, so for matched walls via the SDK pass match in options or use mount.

For React apps, use the wrapper subpath (React is a peer dependency you already have):

wall.tsx 
import { EndorsEmbed } from "@endors/widgets/react";

<EndorsEmbed embedId={id} className="my-wall" match={formData.education} onMountError={(err) => console.error(err.code)} />

Props: embedId, baseUrl, height, match, timeoutMs, className, style, onMountError. StrictMode-safe and unmount-safe; sync mount failures surface through onMountError instead of throwing during render, and a timeoutMs watchdog is caught by the component for you. The wall loads the same live embed document as the copy-paste snippet, auto-resizes, and updates automatically whenever you change it in Endors.

Matched walls per visitor

Pass a free-form match context and the wall shows testimonials matched to that context at render time (Endors' deterministic matching engine, no API key, no extra round-trip):

js 
// After a form submit — the visitor's own words pick the proof:
mount(document.getElementById("wall"), {
  embedId: "your-embedding-id",
  match: formData.education + ", " + formData.previousWork,
});

Copy-paste equivalent: data-endors-match="…" on the embed div (or data-endors-match-getter="fnName" for popups that only know the context at open time). Details on the Overview page.

endors CLI — scaffold in under a minute

bash 
npx endors init

Detects your package manager and framework (Next.js / React / plain HTML), asks for your embedding id (from Embeds → your wall → Embed id in the dashboard), installs @endors/widgets, and drops in a working example. Zero dependencies, so npx cold-start stays fast.
