Pre-Call pages

Generates a personalized Pre-Call page for a prospect: optional CRM enrichment, AI proof matching against the workspace, and a shareable page built from one of your templates. Progress is streamed as NDJSON, so you can render status in real time.

This is a metered AI endpoint: 20 requests/minute per key (see Rate limits).

POST /api/spaces/{spaceId}/pre-call-pages/generate

Generates the page and streams progress. Whole request has a 60-second budget.

Request body

FieldTypeRequiredDescription
prospectName string required Prospect's name, up to 200 characters.
prospectEmail string required Prospect's email. Also the idempotency key (10 minutes).
makeWebhookUrl string optional CRM enrichment webhook. Falls back to the workspace default.
templateId string optional Template for the page. Falls back to the workspace default.
pre-call.sh 
curl -N -X POST "https://app.endors.io/api/spaces/$SPACE_ID/pre-call-pages/generate" \
  -H "Authorization: Bearer $ENDOR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "prospectName": "Jane Cooper",
    "prospectEmail": "jane@acmedental.co",
    "templateId": "t-9f2…"
  }'

The stream

The response is application/x-ndjson — one JSON object per line. Read line by line and act on the final complete event:

ndjson 
{"t":"stage","stage":"finding_prospect"}
{"t":"stage","stage":"retrieving_crm"}
{"t":"stage","stage":"matching"}
{"t":"stage","stage":"generating"}
{"t":"stage","stage":"complete","url":"https://app.endors.io/d/Xk29fj","pageId":"p-8a1…"}

A {"t":"error"} line can appear instead of a final stage — codes include no_prospect_data (CRM enrichment returned nothing usable), template_invalid (the template — explicit or workspace default — isn't usable) and persist_failed (the page was generated but couldn't be saved; credits are refunded).

Generation draws AI credits

Each generation meters 2 AI credits from the space's balance. An empty balance returns 402 AI_CREDITS_EXHAUSTED with a paywall payload — retrying the same request cannot succeed until credits are topped up. Failed generations are refunded.

Idempotent within 10 minutes

A repeat call for the same prospect email within 10 minutes returns the existing page with existing: true and its URL instead of generating a duplicate — and burning a second credit.

API-key callers attribute the generated page to the space owner; the dashboard's own generate flow is unchanged.
