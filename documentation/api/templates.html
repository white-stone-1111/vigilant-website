Templates

The system template library is the discovery surface for widget and Pre-Call page templates. Use it to find templateId values and inspect each template's config schema before building an embedding or generating a page. These routes are not space-scoped — your key's space still authorizes the call.

List the library

GET /api/templates/library

Lists all system templates (walls of love, carousels, cards) with their config schemas. Optional ?type= filter: video, text, image, document or transformation.

bash 
curl "https://app.endors.io/api/templates/library?type=video" \
  -H "Authorization: Bearer $ENDOR_API_KEY"
json 
{
  "ok": true,
  "data": [
    {
      "id": "fs-video-carousel-2-v1",
      "system_key": "video-carousel-2-v1",
      "name": "Spotlight Carousel",
      "testimonial_type": "video",
      "layout_type": "full",
      "default_config": { "…": "…" },
      "config_schema": { "…": "…" },
      "preview_image_url": "https://…"
    }
  ]
}

Get one template

GET /api/templates/library/{templateId}

One template, fully hydrated. Pass ?include_code=true to get the raw HTML/JS template code. Supports UUID ids for DB-backed system templates and fs-… ids for registry entries. Returns 404 NOT_FOUND otherwise.

Workspace templates

Per-space templates live at /api/spaces/{spaceId}/templates (list and read are key-accessible). Creating, editing, cloning and deleting space templates — and embeddings themselves — are dashboard-session-only for now.
