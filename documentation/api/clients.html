Clients

Clients are the people behind the proof. Create them with the same payload the dashboard uses, list them with full profile and CRM fields, and pull the testimonials attached to any one of them.

List clients

GET /api/spaces/{spaceId}/clients

Returns all non-deleted clients in the space with full profile and CRM fields, including custom field values. No pagination — the entire list is returned.

bash 
curl "https://app.endors.io/api/spaces/$SPACE_ID/clients" \
  -H "Authorization: Bearer $ENDOR_API_KEY"

Create a client

POST /api/spaces/{spaceId}/clients

Creates a client with the same payload as the dashboard's create form — billing gates and the client.created webhook fire identically.

FieldTypeRequiredDescription
first_name string required Client's first name.
last_name, email, company, phone, website, job_title, location, notes string optional Profile fields. Email is lowercased on write.
product, service, outcome, industry, business_type, customer_segment, gender string optional Context fields used by proof match and AI search.
quote string optional Short pull-quote, max 150 characters.
tags string[] optional Free-form tags.
custom_field_values object optional Values keyed by custom field.
profile_image_url, company_logo_url string optional Image URLs shown on widgets.
status string optional active (default), inactive or paused.
create-client.sh 
curl -X POST "https://app.endors.io/api/spaces/$SPACE_ID/clients" \
  -H "Authorization: Bearer $ENDOR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "first_name": "Sarah",
    "last_name": "Mitchell",
    "email": "sarah@northwind.io",
    "company": "Northwind",
    "industry": "Dental",
    "tags": ["case-study", "q4"]
  }'

# → 201 { "ok": true, "data": { "clientId": "7a1e…", "first_name": "Sarah", … } }
You often don't need this call

Creating a testimonial with client_first_name + client_email find-or-creates the client for you — use this endpoint when you want the client to exist before any proof does.

List a client's testimonials

GET /api/spaces/{spaceId}/clients/{clientId}/testimonials

Lists the testimonials attached to one client, newest first, with expanded asset URLs. Hard limit of 50 rows.

json 
{
  "ok": true,
  "data": [
    {
      "id": "b3f2…",
      "type": "text",
      "text_content": "They cut our CAC nearly in half in six months.",
      "rating": 5,
      "status": "approved",
      "active_asset": null
    }
  ]
}
