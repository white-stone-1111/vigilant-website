Testimonials

Testimonials are the core proof object — text quotes, videos, images, documents, or before/after transformations, each optionally linked to a client. All four operations go through the same pipeline as the dashboard, so plan limits, webhooks and analytics behave identically.

GET /api/spaces/{spaceId}/testimonials

Lists non-deleted testimonials, newest first — up to the default limit of 200 per page. Supports filters and response extras via query parameters.

List testimonials

Query parameters:

ParameterTypeDescription
type string Filter by type: text, video, image, document or transformation.
folderId string Only testimonials in this folder.
id string Fetch specific ids.
limit integer Page size. Defaults to 200, capped at 500. Caps the page with or without a cursor.
cursor string Opaque pagination cursor (see Pagination).
folder_ids 1 Adds a folder_ids array to every row.
shareLinks 1 Adds shareUrl (the public share page URL) to every row.
skipUrls 1 Skip URL generation for lighter responses.
clientId string Only testimonials linked to this client.
status string Filter by status (e.g. approved).

Request

bash 
curl "https://app.endors.io/api/spaces/$SPACE_ID/testimonials?shareLinks=1&limit=50" \
  -H "Authorization: Bearer $ENDORS_API_KEY"

Response

json 
{
  "ok": true,
  "data": [
    {
      "id": "b3f2…",
      "type": "text",
      "name": "Sarah Mitchell",
      "text_content": "They cut our CAC nearly in half in six months.",
      "rating": 8,
      "status": "approved",
      "client_id": "7a1e…",
      "clients": {
        "id": "7a1e…",
        "first_name": "Sarah",
        "last_name": "Mitchell",
        "company": "Northwind",
        "email": "sarah@northwind.io"
      },
      "active_asset": null,
      "before_asset": null,
      "shareUrl": "https://app.endors.io/share/ab12cd34ef"
    }
  ]
}

Each row comes with client info and fully expanded media URLs — video embed/HLS/poster/player, image WebP transforms with srcset, and document public URLs. Video rows also carry any trim/poster-time overrides.

Pagination (optional)

Purely additive — a request without cursor returns exactly the same set it always did, with no nextCursor. Pass limit with cursor to page:

page.sh 
# plain list — limit caps the page; no cursor passed, so no nextCursor
curl "https://app.endors.io/api/spaces/$SPACE_ID/testimonials?limit=100" \
  -H "Authorization: Bearer $ENDORS_API_KEY"

# → { "ok": true, "data": [ … 100 rows … ] }

# opt in to pagination — pass a cursor to start keyset paging;
# the response carries nextCursor when the page filled

# next page — echo the cursor back
curl "https://app.endors.io/api/spaces/$SPACE_ID/testimonials?limit=100&cursor=eyJ2Ijoi…" \
  -H "Authorization: Bearer $ENDORS_API_KEY"

nextCursor appears only when the page filled. Keep passing the latest value until a response omits it — that's the last page. Pagination uses keyset semantics on (source_created_at, id), so pages are stable even while new testimonials are being created — you never see a row twice or skip one. The cursor is opaque: treat it as a string, don't parse or construct it. Malformed input returns 400 INVALID_LIMIT or 400 INVALID_CURSOR with a field naming the offending parameter. INVALID_LIMIT only fires when a cursor was passed; a malformed limit on a cursor-less request is silently coerced to the default.

Create a testimonial

POST /api/spaces/{spaceId}/testimonials

Creates a testimonial through the same pipeline as the dashboard's manual create: plan limits are enforced, the client is found or created, assets are validated and linked, a share URL is minted, and the testimonial.created webhook fires.

Body parameters:

FieldTypeRequiredDescription
type string required text, video, image, document or transformation.
text_content string required The quote. Required when type is text.
asset_id string required Pre-created via asset upload (image/document) or video create-upload. Required for media types.
before_asset_id string optional The "before" image for a transformation. Forces type to transformation.
name, rating, source_created_at mixed optional Display name, 1–10 rating, and a back-dated creation timestamp.
client_id string optional Link an existing client. Omit to create an unlinked testimonial.
client_first_name + detail fields string optional When client_id is absent, a provided client_first_name triggers find-or-create: lookup by client_email, then client_phone, else a new client. Detail fields: client_last_name, client_email, client_phone, client_company, client_website, client_job_title, client_location, client_product, client_service, client_outcome, client_industry, client_business_type, client_customer_segment, client_gender, client_profile_image_url, client_company_logo_url.
folder_ids string[] optional Folders to add the testimonial to. Validated before insert — an unknown id fails the whole request with nothing written.
create-testimonial.sh 
curl -X POST "https://app.endors.io/api/spaces/$SPACE_ID/testimonials" \
  -H "Authorization: Bearer $ENDORS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "type": "text",
    "text_content": "Working with them doubled our demo book rate.",
    "rating": 8,
    "name": "Sarah Mitchell",
    "client_first_name": "Sarah",
    "client_last_name": "Mitchell",
    "client_email": "sarah@northwind.io",
    "client_company": "Northwind",
    "folder_ids": ["9c4e…"],
    "source_created_at": "2026-10-02T14:30:00Z"
  }'
json 
{
  "ok": true,
  "data": {
    "testimonialId": "b3f2…",
    "clientId": "7a1e…",
    "shareUrl": "https://app.endors.io/share/ab12cd34ef"
  }
}

For an unlinked testimonial clientId is omitted, not null. shareUrl can be null.

Client linking is optional

Omit both client_id and client_first_name to create an unlinked testimonial. Plan limits count every type; transformations consume one image slot.

Fail-fast validation

Asset, client and folder ids are all validated against the space before anything is written. A bad reference fails the whole request with 404 — you never get a half-created testimonial.

Retrieve a testimonial

GET /api/spaces/{spaceId}/testimonials/{testimonialId}

Fetches one testimonial with client info and its active asset expanded — Cloudflare Stream playback URLs for video, or a 1-hour signed URL for storage files.

Query parameters: folder_ids=1 adds the folder membership array; shareLink=1 adds shareUrl. Returns 404 NOT_FOUND when the testimonial is missing or deleted.

Update a testimonial

PATCH /api/spaces/{spaceId}/testimonials/{testimonialId}

Updates editable fields, manages folder membership the same way Google Drive's API manages parents, reassigns the client, and can mint the share link — all in one call.

FieldTypeDescription
text_content, rating, status, body, author_name, author_title mixed Editable fields. status is unreviewed / pending_review / approved / not_approved — any other value is rejected by the database check.
add_folder_ids string[] Add the testimonial to these folders (idempotent).
remove_folder_ids string[] Remove it from these folders. May be combined with add_folder_ids.
client_id string | null Reassign the linked client, or null to unlink.
ensureShareLink boolean Mint the share id if missing and return shareUrl.

Unknown folder or client ids fail the whole request with 404 and nothing is written.

move-to-folder.sh 
curl -X PATCH "https://app.endors.io/api/spaces/$SPACE_ID/testimonials/$T_ID" \
  -H "Authorization: Bearer $ENDORS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "add_folder_ids": ["9c4e…"],
    "remove_folder_ids": ["1d7f…"],
    "status": "approved",
    "ensureShareLink": true
  }'

# → { "ok": true, "shareUrl": "https://app.endors.io/share/ab12cd34ef" }
