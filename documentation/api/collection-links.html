Collection links

Collection links are the pages customers fill in to submit proof. Create them with the same configuration JSON the dashboard's link builder produces — page personalization, guided questions, after-submission behavior — merged over your space's defaults.

List collection links

GET /api/spaces/{spaceId}/collection-links

Lists collection links with their full configuration. Query parameters: status (active | inactive), clientId, limit (default 100, clamped 1–500). Each row includes url — the public /r/{short_id} collection page.

json 
{
  "ok": true,
  "data": [
    {
      "id": "cl-3a8…",
      "name": "Q4 outreach",
      "slug": "q4-outreach",
      "short_id": "ab12cd34",
      "url": "https://app.endors.io/r/ab12cd34",
      "testimonial_type": "video",
      "link_type": "collection",
      "client_id": null,
      "status": "active",
      "configuration": { "…": "…" },
      "created_at": "2026-10-01T09:00:00Z"
    }
  ]
}

Create a collection link

POST /api/spaces/{spaceId}/collection-links

Creates a collection link. Returns 201 with the serialized link, including the public url and generated short_id.

FieldTypeRequiredDescription
name string optional Display name for the dashboard.
testimonial_type string optional video, image, text or document. Defaults to text.
collection_type string optional testimonial (default), customer_story or performance_case_study. Case-study links serve the guided-questions form and assemble a case study on submission.
configuration object optional Full collect-page config: pages personalization, guided questions, after-submission, etc. Shallow-merged over defaults — send only the keys you want to override.
mode string optional general or client-specific. Client-specific requires clientId pointing at an existing, non-deleted client (404 otherwise).
clientId string optional Pre-fills the submitter for client-specific links.
autoApprove boolean optional Publish submissions without the review queue.
destinations object optional After-submission redirect configuration. External redirects require the plan feature externalRedirects.
slug, status string optional Custom URL slug (collisions get -2, -3… suffixes) and active/inactive.
create-link.sh 
curl -X POST "https://app.endors.io/api/spaces/$SPACE_ID/collection-links" \
  -H "Authorization: Bearer $ENDOR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Q4 outreach",
    "testimonial_type": "video",
    "mode": "client-specific",
    "clientId": "7a1e…",
    "autoApprove": true,
    "configuration": {
      "headline": "Got 60 seconds? Tell us how it went."
    }
  }'

# → 201 { "ok": true, "data": { "url": "https://app.endors.io/r/ab12cd34", … } }
Plan gates

Link count is capped per plan (403 PLAN_RESTRICTION when exhausted) and external redirects require the externalRedirects feature. Everything else behaves like the dashboard's link builder.
