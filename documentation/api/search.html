AI search

The same engine behind Testimonials → AI Search in the dashboard, exposed over HTTP. Two modes: free lexical keyword search, or ai mode — embedding-based candidate retrieval, LLM reranking, and a synthesized ranked recommendation.

POST /api/spaces/{spaceId}/search

Search the space's proof. Both modes run against the same hybrid search index.

FieldTypeDescription
query string Free-text query, e.g. "dental agency that cut CAC".
mode string keyword (default) or ai.
limit integer Max results. Defaults to 20, capped at 50.
filters object Structured filters passed through to the hybrid search index.
stream boolean AI mode only. Default true streams NDJSON (for the in-app typing effect). Pass false for API use — you get one JSON object whose content is byte-identical to the stream's final state.

Request

bash 
curl -X POST "https://app.endors.io/api/spaces/$SPACE_ID/search" \
  -H "Authorization: Bearer $ENDOR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "query": "dental agency that cut CAC",
    "mode": "ai",
    "limit": 5,
    "stream": false
  }'

json

Streaming

In AI mode with the default stream: true, the response is an NDJSON stream (Content-Type: application/x-ndjson) of meta → title/item… → answer → end events. Keyword mode ignores stream and always returns one JSON object. For API-key callers, prefer stream: false — the content is identical, just delivered in one body.

Graceful degradation

If an AI stage times out, results are still returned (ranked by the underlying search index) and degraded_reason explains which stage failed. AI search never returns empty — with no indexed matches it falls back to the 50 most recent testimonials. Videos outrank text at equal relevance.
