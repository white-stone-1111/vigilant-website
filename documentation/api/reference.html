Authentication

Authenticate by sending your secret key in the Authorization header as a Bearer token. Keys starting with sk_live_ hit live data; keys starting with sk_test_ hit the sandbox. Never expose secret keys in client-side code — use a public key (pk_live_…) for widgets.

bash 
curl https://api.endors.io/v1/testimonials \
  -H "Authorization: Bearer sk_live_4f9d8c2b7a1e"
js 
import Endors from "@endors/sdk";

const endors = new Endors("sk_live_4f9d8c2b7a1e");

const testimonials = await endors.testimonials.list({ limit: 10 });
python 
import endors

client = endors.Client("sk_live_4f9d8c2b7a1e")

testimonials = client.testimonials.list(limit=10)

GET /v1/spaces/{space_id}/testimonials

Query parameters:

ParameterTypeDescription
limit integer Items per page, 1–100. Defaults to 25.
cursor string Opaque cursor from a previous response's next_cursor field.
status string Filter by status: pending, approved or rejected.
min_rating integer Only return testimonials rated at or above this value (1–5).

Body parameters:

Pagination

All list endpoints use cursor-based pagination. Excepteur sint occaecat cupidatat non proident, sunt in culpa qui officia deserunt mollit anim id est laborum. Keep reading until next_cursor is null:

js 
async function* allTestimonials(endors, spaceId) {
  let cursor = null;
  do {
    const page = await endors.testimonials.list({
      space: spaceId,
      limit: 100,
      cursor,
    });
    for (const t of page.data) yield t;
    cursor = page.next_cursor;
  } while (cursor !== null);
}

StatusCodeWhen it happens
400invalid_requestA parameter failed validation — check message for the field.
401unauthenticatedMissing or malformed Authorization header.
403forbiddenThe key is valid but lacks the required scope.

Rate limits

The default limit is 600 requests per minute per key, returned in the X-RateLimit-Remaining header on every response.

Steps component

Get your API key

Open the dashboard, pick a space, and copy the secret key from Settings → API keys. Keep it server-side only.

Make your first request

Call GET /v1/spaces with your Bearer token. A 200 with a JSON body means the key works.

Handle errors

Match on error.code, back off on 429, and alert on repeated 5xx responses.
