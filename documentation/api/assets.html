Assets & video

Media is uploaded first and linked second: create an asset, then reference its assetId when you create a testimonial. Images and documents go to storage in one call; videos take a three-step direct upload to Cloudflare Stream.

Upload an image or document

POST /api/spaces/{spaceId}/assets/upload

Uploads an image or document to storage and creates the asset row. Send multipart/form-data with a file field and an optional type (image | document, inferred from the MIME type otherwise).

ConstraintValue
Max size50 MB — larger files get 413
ImagesJPEG, PNG, WebP, GIF, SVG, AVIF — anything else gets 415
DocumentsPDF, DOC, DOCX, TXT, RTF, Markdown, PPT, PPTX — anything else gets 415
upload-asset.sh 
curl -X POST "https://app.endors.io/api/spaces/$SPACE_ID/assets/upload" \
  -H "Authorization: Bearer $ENDORS_API_KEY" \
  -F "type=image" \
  -F "file=@headshot.jpg"

# → 201 { "assetId": "a-9f2…", "status": "ready" }
Bare response shape

This endpoint predates the standard envelope — it returns { "assetId": "…", "status": "ready" } directly, not { "ok": true, "data": … }.

Filenames are sanitized to [A-Za-z0-9._-], truncated to 80 characters, and stored under {spaceId}/manual/…. If the asset row fails to insert, the uploaded object is removed again.

Upload a video

Videos go through Cloudflare Stream direct upload. Max 1 GB, max 5 minutes, MP4/WebM/MOV only — larger or unsupported files fail at step 1 with 413 / 415.

1. Create the upload

Call POST /api/video/create-upload with { "spaceId": "…" } (plus optional filename, contentType, fileSize). Returns { uploadUrl, assetId, streamUid } — another bare shape.

2. POST the file to Cloudflare

Send the raw video bytes as the body of a POST to the returned uploadUrl — no auth header, the URL is pre-signed. Cloudflare processes and encodes the video.

3. Poll status, then create the testimonial

Call GET /api/video/status?assetId={assetId} until status is ready, then create the testimonial with asset_id.

upload-video.sh 
# 1. create the upload
curl -X POST "https://app.endors.io/api/video/create-upload" \
  -H "Authorization: Bearer $ENDORS_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{ "spaceId": "'"$SPACE_ID"'", "filename": "demo.mp4" }'
# → { "uploadUrl": "https://upload.cloudflarestream.com/…", "assetId": "a-7c1…", "streamUid": "…" }

# 2. push the bytes to Cloudflare (no auth header)
curl -X POST "$UPLOAD_URL" --data-binary @demo.mp4

# 3. poll until ready
curl "https://app.endors.io/api/video/status?assetId=$ASSET_ID" \
  -H "Authorization: Bearer $ENDORS_API_KEY"
# → { "assetId": "a-7c1…", "status": "ready", "embedUrl": "…", "hlsUrl": "…",
#     "posterUrl": "…", "durationSeconds": 84, "aspectRatio": "16:9" }
Status self-heals

The status endpoint probes Cloudflare directly while a video is still uploading/processing and persists the real state — including a durable first-frame poster — so you never get stuck polling a stale value.

List existing assets

GET /api/spaces/{spaceId}/assets

Lists ready image (or document) assets for "link an existing" flows. Query: type (image default | document). Returns up to 120 rows, newest first, each with id, url, srcset, original_filename, mime_type and created_at. Session-only — API keys are not accepted on this read route.
